## Описание на проекта

Курсова работа върху онлайн платформата Netflix. Проектът включва:

- концептуален модел (Chen's notation);
- логически модел (Crow's Foot notation) с 15 таблици, 72 атрибута и 3 връзки много към много;
- релационна база данни в MS SQL Server със съхранени процедури, функции, тригер и изглед;
- Data Warehouse (звездна схема) с 3 таблици факти и 8 таблици измерения;
- Power BI доклад с визуализации върху данните.

Пълно описание на проекта, бизнес правилата и архитектурата: [PROJECT_DESCRIPTION.md](PROJECT_DESCRIPTION.md).

## Основни обекти в базата

| Таблица | Описание |
|---|---|
| Countries, Plans | Държави и абонаментни планове |
| Accounts, Profiles | Акаунти и профили в тях |
| Titles, Seasons, Episodes | Филми, сериали, сезони и епизоди |
| Genres, Title_Genres | Жанрове (M:N със заглавията) |
| People, Title_Cast | Актьори и режисьори (M:N със заглавията) |
| Watchlist | Списък за гледане (M:N профил - заглавие) |
| ViewingHistory, Ratings | История на гледане и оценки |
| Payments | Плащания на акаунтите |

### Програмни обекти

| Обект | Име | Предназначение |
|---|---|---|
| Процедура | `sp_AddViewing` | Добавя гледане след валидация на входните данни |
| Функция | `fn_ProfileWatchMinutes` | Общо изгледани минути от профил |
| Функция | `fn_AccountMonthlyCost` | Месечна цена на акаунт според плана |
| Тригер | `trg_Profiles_MaxLimit` | Не позволява повече профили от лимита на плана |
| Изглед | `vw_TopTitles` | Гледания, минути и средна оценка по заглавие |

## Изисквания

- Microsoft SQL Server 2016 SP1 или по-нова версия (може и Express)
- SQL Server Management Studio (SSMS)
- Power BI Desktop

## Инсталация и стартиране

### 1. Операционна база данни

1. Отвори SSMS и се свържи със своя SQL Server.
2. Изпълни `sql/schema.sql`. Той създава базата `NetflixDB` и всички обекти в нея.
3. Изпълни `sql/seed.sql`. Той попълва базата с данни и пуска няколко тестови заявки.

### 2. Data Warehouse

1. Изпълни `sql/dwh_schema.sql`. Той създава базата `NetflixDWH` с таблиците факти и измерения.
2. Изпълни `sql/etl.sql`. Той зарежда данните от `NetflixDB` в `NetflixDWH`.

### 3. Power BI доклад

1. Отвори `powerbi/netflix_report.pbix` в Power BI Desktop (стъпките за изграждане са в `powerbi/powerbi_guide.md`).
2. При нужда смени източника на данни: **Transform data -> Data source settings** и сложи името на твоя сървър.
3. Натисни **Refresh**.

## Визуализации в доклада

1. Изгледани часове по месеци (линейна диаграма)
2. Топ 10 заглавия по гледания (стълбовидна диаграма)
3. Приходи по абонаментен план (пръстенна диаграма)
4. Гледания по държава (карта)
5. Средна оценка по жанр (стълбовидна диаграма)

Докладът има филтри (slicers) по период, жанр и държава.
